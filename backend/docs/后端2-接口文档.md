# 后端2 接口文档（班级模块 + 实训任务模块）

> 负责人：施炀（后端2｜feature/task-class）
> 本模块接口全部遵循【统一接口规范】与组长下发的【接口文档】路径约定，未做任何私自改动。

## 通用约定

- 统一前缀：`/api`
- 数据格式：`JSON`
- 需登录的接口请求头携带：`Authorization: Bearer {token}`（token 由后端1 登录接口返回）
- 日期统一字符串：`yyyy-MM-dd HH:mm:ss`

### 统一返回体

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}
```

状态码说明：

| code | 含义 |
|------|------|
| 200  | 成功 |
| 400  | 参数错误（缺少必填字段、JSON/日期格式错误） |
| 401  | 未登录 / token 失效 |
| 404  | 资源不存在 |
| 500  | 服务器异常 |

### 分页 data 结构（固定）

```json
{
  "records": [],
  "total": 100,
  "current": 1,
  "size": 10
}
```

## 一、班级模块（class）

### 1. 班级分页查询

- 请求地址：`GET /api/class/page`
- 请求参数（url query）：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| current | long | 否 | 页码，默认 1 |
| size | long | 否 | 每页条数，默认 10 |
| className | string | 否 | 班级名称模糊查询 |

- 请求示例：`GET /api/class/page?current=1&size=10&className=计算机`
- 返回示例：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "records": [
      {
        "id": 1,
        "className": "2025计算机1班",
        "teacherId": 2,
        "createTime": "2026-10-12 16:00:00",
        "updateTime": "2026-10-12 16:00:00",
        "isDeleted": 0
      }
    ],
    "total": 1,
    "current": 1,
    "size": 10
  }
}
```

### 2. 根据 id 查询班级

- 请求地址：`GET /api/class/{id}`
- 请求示例：`GET /api/class/1`
- 返回 data：班级对象（结构同上 records 中的单条）

### 3. 新增班级

- 请求地址：`POST /api/class`
- 请求体：

```json
{
  "className": "2025计算机1班",
  "teacherId": 1
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| className | string | 是 | 班级名称 |
| teacherId | long | 否 | 负责教师 id，可为 null |

- 返回示例：`{"code":200,"msg":"操作成功","data":null}`

### 4. 修改班级

- 请求地址：`PUT /api/class/{id}`
- 请求体：同新增（`className` 为空则不修改名称）
- 返回示例：`{"code":200,"msg":"操作成功","data":null}`

### 5. 删除班级（逻辑删除）

- 请求地址：`DELETE /api/class/{id}`
- 返回示例：`{"code":200,"msg":"操作成功","data":null}`

## 二、实训任务模块（training-task）

### 1. 任务分页查询

- 请求地址：`GET /api/training-task/page`
- 请求参数（url query）：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| current | long | 否 | 页码，默认 1 |
| size | long | 否 | 每页条数，默认 10 |
| classId | long | 否 | 按班级筛选 |
| taskName | string | 否 | 任务名称模糊查询 |

- 请求示例：`GET /api/training-task/page?current=1&size=10&classId=1&taskName=Spring`
- 返回示例：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "records": [
      {
        "id": 1,
        "taskName": "SpringBoot实训",
        "taskDesc": "完成前后端项目开发",
        "classId": 1,
        "totalScore": 100,
        "deadline": "2026-10-30 23:59:59",
        "status": "not_start",
        "createUserId": 2,
        "createTime": "2026-10-12 16:00:00",
        "updateTime": "2026-10-12 16:00:00",
        "isDeleted": 0
      }
    ],
    "total": 1,
    "current": 1,
    "size": 10
  }
}
```

### 2. 查询单个任务详情

- 请求地址：`GET /api/training-task/{id}`
- 返回 data：任务对象（结构同上 records 中的单条）

### 3. 发布新增任务

- 请求地址：`POST /api/training-task`
- 说明：`createUserId`（创建教师）由后端从登录 token 自动获取，**请求体不用传**。
- 请求体：

```json
{
  "taskName": "SpringBoot实训",
  "taskDesc": "完成前后端项目开发",
  "classId": 1,
  "totalScore": 100,
  "deadline": "2026-10-30 23:59:59",
  "status": "not_start"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| taskName | string | 是 | 任务名称 |
| taskDesc | string | 否 | 任务描述 |
| classId | long | 是 | 所属班级 id |
| totalScore | int | 否 | 总分 |
| deadline | string | 否 | 截止时间，格式 yyyy-MM-dd HH:mm:ss |
| status | string | 否 | not_start/ongoing/finished，不传默认 not_start |

- 返回示例：`{"code":200,"msg":"操作成功","data":null}`

### 4. 修改任务

- 请求地址：`PUT /api/training-task/{id}`
- 请求体：同发布（`taskName` 为空则不修改名称）
- 返回示例：`{"code":200,"msg":"操作成功","data":null}`

### 5. 删除任务（逻辑删除）

- 请求地址：`DELETE /api/training-task/{id}`
- 返回示例：`{"code":200,"msg":"操作成功","data":null}`

## 三、错误返回示例

```json
{
  "code": 401,
  "msg": "未登录或token失效",
  "data": null
}
```

资源不存在：

```json
{
  "code": 404,
  "msg": "任务不存在",
  "data": null
}
```

参数错误：

```json
{
  "code": 400,
  "msg": "任务名称不能为空",
  "data": null
}
```
