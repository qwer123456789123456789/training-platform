# 后端2 接口文档（班级模块 + 实训任务模块）

> 负责人：施炀（后端 2｜feature/task-class）
> 技术栈已对齐后端 1：Spring Boot 4.1.1 + JdbcTemplate，包名 `com.util.demo2`
> 接口路径严格按组长下发的【接口文档】实现，未私自改动。

## 通用约定

- 统一前缀：`/api`
- 数据格式：`JSON`
- 需登录接口请求头携带 token：`Authorization: Bearer {token}` 或 `token: {token}`（两种都支持，与后端 1 一致）
- 日期统一字符串：`yyyy-MM-dd HH:mm:ss`

### 统一返回体

```json
{ "code": 200, "msg": "操作成功", "data": {} }
```

| code | 含义 |
|------|------|
| 200 | 成功 |
| 400 | 参数错误 / 业务校验失败 |
| 401 | 未登录 / token 无效或过期 |
| 403 | 已登录但权限不足 |
| 500 | 服务器异常 |

> HTTP 状态码一律返回 200，前端 axios 请判断 `res.data.code`，不要判断 HTTP 状态码。

### 分页 data 结构（固定）

```json
{ "records": [], "total": 100, "current": 1, "size": 10 }
```

## 一、班级模块（class）

权限：查询只需登录；新增/修改/删除需 **admin 或 teacher**。

### 1. 班级分页查询 `GET /api/class/page`

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| current | long | 否 | 页码，默认 1 |
| size | long | 否 | 每页条数，默认 10 |
| className | string | 否 | 班级名称模糊查询 |

返回 data：

```json
{
  "records": [
    {
      "id": 1,
      "className": "2025计算机1班",
      "teacherId": 2,
      "teacherName": "王老师",
      "createTime": "2026-10-13 10:00:00",
      "updateTime": "2026-10-13 10:00:00"
    }
  ],
  "total": 1, "current": 1, "size": 10
}
```

### 2. 查询单个班级 `GET /api/class/{id}`

返回 data：班级对象（`teacherName` 字段为 null，其余同上）。

### 3. 新增班级 `POST /api/class`

请求体：

```json
{ "className": "2025计算机1班", "teacherId": 1 }
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| className | string | 是 | 班级名称，≤50 字符 |
| teacherId | long | 否 | 负责教师 id，传了必须真实存在且为 teacher |

返回 data：新班级 id（Long）。

### 4. 修改班级 `PUT /api/class/{id}`

请求体同新增，字段均可选（传了才改）。

### 5. 删除班级（逻辑删除）`DELETE /api/class/{id}`

## 二、实训任务模块（training-task）

权限：查询只需登录（学生要看任务）；发布/修改/删除需 **admin 或 teacher**。

### 1. 任务分页查询 `GET /api/training-task/page`

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| current | long | 否 | 页码，默认 1 |
| size | long | 否 | 每页条数，默认 10 |
| classId | long | 否 | 按班级筛选 |
| taskName | string | 否 | 任务名称模糊查询 |

返回 data：

```json
{
  "records": [
    {
      "id": 1,
      "taskName": "SpringBoot实训",
      "taskDesc": "完成前后端项目开发",
      "classId": 1,
      "className": "2025计算机1班",
      "totalScore": 100,
      "deadline": "2026-12-31 23:59:59",
      "status": "not_start",
      "createUserId": 2,
      "createTime": "2026-10-13 10:00:00",
      "updateTime": "2026-10-13 10:00:00"
    }
  ],
  "total": 1, "current": 1, "size": 10
}
```

### 2. 查询单个任务 `GET /api/training-task/{id}`

返回 data：任务对象（`className` 字段为 null，其余同上）。

### 3. 发布任务 `POST /api/training-task`

> `createUserId` 由后端从登录 token 自动获取，请求体不用传。

请求体：

```json
{
  "taskName": "SpringBoot实训",
  "taskDesc": "完成前后端项目开发",
  "classId": 1,
  "totalScore": 100,
  "deadline": "2026-12-31 23:59:59",
  "status": "not_start"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| taskName | string | 是 | 任务名称，≤100 字符 |
| taskDesc | string | 否 | 任务描述 |
| classId | long | 是 | 所属班级 id，必须真实存在 |
| totalScore | int | 否 | 总分，≥0 |
| deadline | string | 否 | 截止时间，`yyyy-MM-dd HH:mm:ss` |
| status | string | 否 | `not_start`/`ongoing`/`finished`，默认 `not_start` |

返回 data：新任务 id（Long）。

### 4. 修改任务 `PUT /api/training-task/{id}`

请求体同发布，字段均可选（传了才改，不传保持原值）。

### 5. 删除任务（逻辑删除）`DELETE /api/training-task/{id}`
