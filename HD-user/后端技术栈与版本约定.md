## 二、明确"没有用"的东西（不要按"肯定有"去写代码）

| 没有引入 | 用什么代替 |
|---|---|
| **Lombok** | 实体 / DTO / VO 全是**手写 getter / setter**，没有 `@Data`、`@Slf4j` |
| **MyBatis-Plus / MyBatis** | `JdbcTemplate` 手写 SQL（`UserRepository`） |
| **Spring Security 全栈** | 自定义 `AuthInterceptor` + `@RequireRole`，只借用 BCrypt 工具类 |
| jwt 第三方库（jjwt 等） | 手写 `JwtUtil` |
| JPA / Hibernate ORM | 同上，SQL 手写 |
| Redis / MQ / Nginx | 本项目范围内不需要 |

## 三、Boot 4 与网上 Boot 3 教程的 4 个差异（照抄教程会报错）

1. **包名全体 `jakarta.*`**：`javax.servlet` / `javax.validation` 已作废。
2. **Jackson 3**：`tools.jackson.databind.ObjectMapper`（不是 `com.fasterxml.jackson.databind`）。
3. **JUnit 是 6.0.3**：注解包名仍是 `org.junit.jupiter.api.*`，但断言/扩展有签名变化，编译报错优先查 JUnit 6 文档。
4. **starter 被拆成模块**：实际引入的是 `spring-boot-webmvc / -jdbc / -tomcat / -servlet / -validation / -jackson / -transaction …`，排查依赖时以实际 jar 为准。

| 项 | 要求 | 本机实际 |

| MySQL | 8.x，且已执行 `database/create-database.sql` 建库 | 8.0.37 |
| 端口 | 8080（`server.port`），联调时只由一个人启动 | |


## 五、版本/技术选错时的典型症状

| 症状 | 原因 |
|---|---|
| `找不到符号 javax.servlet.*` / `javax.validation.*` | 抄了 Boot 3.x 教程代码，必须改成 `jakarta.*` |
| `ClassNotFoundException: com.fasterxml.jackson...` 或序列化行为不对 | 按 Jackson 2 的包名写的，Boot 4 是 `tools.jackson.*` |
| 加了 MyBatis-Plus 后启动失败 / 自动装配报错 | MP 主线面向 Boot 3.x，与本工程不兼容；本模块用 JdbcTemplate |
| `getXxx() 找不到` | 以为有 Lombok；本工程是手写 getter/setter |
| 测试编译不过 | JUnit 版本差异（本工程 Jupiter 6.0.3） |
| 编译报 `release 21` 不支持 | JDK 低于 21 |
| 启动报 `Unknown database` / `Access denied` | 没建库 / `application.properties` 里密码不是自己的 |
| 启动报 `app.jwt.secret 长度不能小于 32` | 密钥被改短（必须 ≥ 32 个字符） |
| 离线执行 `package` 失败 | `spring-boot-maven-plugin` 的依赖未缓存，联网跑一次即可 |
| 控制台 `Mockito is currently self-attaching...` | JDK 21 下的已知提示，**不影响测试结果** |
